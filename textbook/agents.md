# ITM-2100 Textbook Drafting Instructions

You are drafting the first version of a new undergraduate textbook for ITM-2100.

## Goal
Produce clean first drafts for textbook chapters, in Markdown, aligned to the course’s milestone flow:
1. proposed entities
2. ER diagram
3. database design diagram
4. SQL Server implementation

## Deliverables
Create these files:
- /textbook/chapters/01-why-databases-matter.md
- /textbook/chapters/02-sql-server-environment.md
- /textbook/chapters/03-single-table-queries.md
- /textbook/chapters/04-joins-and-grouping.md

## Source priority
Use, in order:
1. local course files and plans
2. approved chapter/outcome maps in this repo
3. official documentation for technical verification only

Do not invent course policies, rubrics, citations, or chapter requirements.

## Chapter template
Each chapter must include:
- Title
- Purpose
- Learning outcomes
- Section-by-section draft prose
- Worked examples
- Common mistakes
- Quick check
- Lab
- Project checkpoint
- Key terms

## Style
- Plain, concise, instructor-friendly
- Undergraduate reading level
- SQL Server terminology
- Project-driven, not encyclopedia-style
- No fluff
- No fake citations
- Mark uncertainty as “Hypothesis”

## Drafting rules
- Draft complete prose, not notes
- Prefer realistic business examples
- Keep headings consistent across chapters
- Use Markdown only
- Preserve compatibility with later conversion to DOCX

## Quality bar
Before finishing:
- verify technical SQL claims against official docs when needed
- keep terminology consistent
- ensure each chapter supports the semester project
- flag any missing source material clearly

# ITM-2100 v4 Lesson Assignments and Activities

## Purpose

This directory defines the lesson-level assignments and activities for `ITM-2100 v4`.

The activities are designed for a fully asynchronous, AI-available course. They are meant to create evidence of explanation, diagnosis, comparison, adaptation, or verification rather than only polished artifact production.

Lakeside Tutoring Center is the primary running case. Cedar Valley Community Clinic is the alternative case for further discussion or extension resources.

## Files

- `01-lesson-assignments-and-activities.md`
  Provides one activity or assignment pattern for each v4 lesson.

## Use

Use these activities when building LMS pages, weekly work modules, practice checks, or low-stakes assignments. Module-level graded assessments remain defined in `textbook/v4/assessments/02-module-level-assessment-briefs.md`.

## Rule

When an activity asks students to produce an artifact, require a second evidence element such as an annotation, short explanation, critique, verification note, or revision decision.

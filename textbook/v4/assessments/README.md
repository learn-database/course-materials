# ITM-2100 v4 Assessment Artifacts

## Purpose

This directory collects the v4 assessment artifacts derived from:

- `textbook/v4/00-course-design-spec.md`
- `textbook/v4/02-instructional-strategies-for-lessons.md`
- `textbook/v4/modules-plan/`

These files make the v4 assessment design usable for course building, assignment setup, rubric writing, and LMS implementation.

## Files

- `01-lesson-level-assessment-map.md`
  Maps every lesson to its intended assessment evidence.
- `02-module-level-assessment-briefs.md`
  Defines the eight module assessments, their prompts, evidence types, and grading focus.
- `03-course-level-assessment-plan.md`
  Defines the course-wide assessment architecture, weighting targets, and capstone-level expectations.

## Core Rule

v4 does not treat polished artifacts alone as strong evidence of learning. Every major artifact-producing task should be paired with a second evidence type that reveals explanation, diagnosis, comparison, adaptation, or verification.
